Laboratório Python · Tutorial 1

Explorando indicadores populacionais com Python

Iniciante25 minGoogle Colab ou Jupyter

Pergunta de pesquisa

Como comparar a estrutura etária e a proporção de pessoas idosas em municípios?

O que você aprenderá

  • Tabelas e variáveis
  • Pandas e indicadores simples
  • Visualização e interpretação
Abrir no Google Colab ↗Baixar notebook (.ipynb)

O botão Colab funcionará depois da publicação dos notebooks no GitHub, na ramificação main.

Passo a passo: execute cada célula em sequência. Todos os dados dos exemplos são sintéticos. Para os tutoriais 5 e 6, o uso de LLM é opcional e exige download adicional.

Execução passo a passo

Passo 1 — Preparar o ambiente

Vamos usar apenas bibliotecas comuns de análise de dados.

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
print("Ambiente pronto!")

Passo 2 — Criar dados sintéticos

Os valores são fictícios e servem apenas à exploração da análise.

rng = np.random.default_rng(42)
municipios = ["Município A", "Município B", "Município C", "Município D", "Município E"]
pop = np.array([10000, 20000, 12000, 18000, 15000])
pct_idosos = np.array([10, 18, 14, 23, 8])
df = pd.DataFrame({"municipio": municipios, "populacao": pop, "pct_60mais": pct_idosos})
df["pessoas_60mais"] = (df.populacao * df.pct_60mais / 100).round().astype(int)
df

Passo 3 — Calcular indicadores

A média simples dos percentuais municipais não equivale à proporção populacional agregada.

total = df["populacao"].sum()
pessoas_idosas = df["pessoas_60mais"].sum()
print("População total:", total)
print("Proporção ponderada de pessoas 60+ (%):", round(100*pessoas_idosas/total, 2))

Passo 4 — Visualizar

Compare as barras: o gráfico não permite concluir por que os municípios diferem.

ax = df.plot.bar(x="municipio", y="pct_60mais", legend=False, figsize=(9,4))
ax.set_ylabel("População de 60 anos ou mais (%)")
ax.set_xlabel("Município (fictício)")
plt.xticks(rotation=25, ha="right")
plt.tight_layout()
plt.show()

Agora é sua vez

Modifique os percentuais e observe como muda a proporção ponderada. Calcule também a média simples e compare os resultados.

Limitações metodológicas

Dados sintéticos, sem representatividade real; a definição operacional de idoso e a qualidade das estimativas afetam comparações.
