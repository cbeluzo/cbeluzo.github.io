# IA em Estudos Populacionais — ABEP 2026

Material didático do minicurso **Da Regressão à IA Generativa**.

Site HTML estático para GitHub Pages. A página inicial é `index.html`.

Organização: `topicos/`, `recursos/`, `assets/` e `dados/`.

Esta versão inicial traz a navegação e páginas-base; o conteúdo será desenvolvido progressivamente.


## Apresentação HTML — Tópico 1

Abra `topicos/fundamentos/index.html`. Navegue com as setas do teclado, espaço ou botões. Pressione **F** para tela cheia. Os slides públicos não contêm notas de apresentação. Não há dependências externas.


## Tutoriais

Os seis tutoriais encontram-se em `tutoriais/`. Cada um contém página HTML e `tutorial.ipynb`, executável no Jupyter ou no Google Colab após a publicação na branch `main`. Exemplos utilizam dados sintéticos. Tutoriais 5 e 6 têm etapa opcional de download de um LLM externo.
